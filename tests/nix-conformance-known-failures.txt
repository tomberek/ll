# Search path given with -I, which the adapter turns into a $NIX_PATH
# entry. A name=path entry is not honoured by compiler.c's
# resolve_search_path: <dir5/c.nix> with dir5=lang/dir3 looks for
# /lang/dir3/dir5/c.nix instead of lang/dir3/c.nix, and <a/b/a.nix> with
# a/b=lang/dir3 is not found. eval-okay-search-path also reads
# __nixPath, which is not defined.
